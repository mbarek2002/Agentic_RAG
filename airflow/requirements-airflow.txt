# pyproject.toml here would risk pulling packages that conflict with what
# Airflow itself needs.

# airflow-specific requires otherwise - confirm against pyproject.toml if
# either changes.

# select()/session.scalars() calls still work under 1.4 (it supports both
# APIs) - verified working here via airflow/dags/arxiv_ingestion/indexing.py,
